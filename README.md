# Web Data Extraction Pipeline

Python-based web scraping project that extracts structured data from web pages and generates clean datasets.

## Features

- Multi-page web scraping
- Hierarchical data extraction
- Data cleaning with Pandas
- CSV and JSON dataset generation
- Error handling and logging

## Tech Stack

Python  
BeautifulSoup  
Selenium  
Pandas  

## Run Project

pip install -r requirements.txt

python main.py

## Output

dataset/books.csv  
dataset/books.json
